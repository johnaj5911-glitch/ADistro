# ADistro
This Project called **ADistro** is specifically made for termux. optimized for anyone who wants to have a working desktop on Termux, Easy and Fast.
1. Download [Termux](https://f-droid.org/repo/com.termux_1002.apk), [Termux-x11](https://github.com/termux/termux-x11/releases/download/nightly/termux-x11-universal-debug.apk).
2. Copy this Link: `
curl -fL "https://github.com/johnaj5911-glitch/ADistro/releases/download/v1.0.0/x" -o x && chmod +x x && ./x
`

Follow the instructions carefully to install it.
