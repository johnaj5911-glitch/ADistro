# ADistro
This Project called **ADistro** is specifically made for termux. optimized for anyone who wants to have a working Linux desktop on Termux, Easy and Fast.
1. Download [Termux](https://f-droid.org/repo/com.termux_1002.apk), [Termux-x11](https://github.com/termux/termux-x11/releases/download/nightly/termux-x11-universal-debug.apk).
2. Copy this Link: `
curl -fL "https://github.com/johnaj5911-glitch/ADistro/releases/download/v1.0.1/x" -o x && chmod +x x && ./x
`
3. After installation type `proot-distro login yourchosendistro --shared-tmp`, `xfce4-session`
4. Swipe left edge to right, and new session. type `termux-x11 :0` and open termux x11.
